第35章 Spearman相关

案例题目

秩相关分析：探讨患者年龄与疼痛评分（非正态分布）的Spearman相关

设计思路

临床数据常不满足正态分布，Pearson相关不适用。本例模拟20例慢性疼痛患者数据，年龄与疼痛VAS评分（0-10），其中VAS呈偏态分布。使用cor(method='spearman')计算秩相关系数，并给出检验p值，帮助学习者掌握非参数相关的实现与解读。

核心代码

# 模拟数据（固定种子保证可复现）
set.seed(42)
n <- 20
age <- round(rnorm(n, 55, 12), 1)
# 构造偏态VAS评分（多数低分，少数高分）
vas <- round(rbeta(n, 2, 5) * 10, 1)

# Spearman相关
rho <- cor(age, vas, method = "spearman")
# 相关检验（输出p值）
test <- cor.test(age, vas, method = "spearman")

# 输出结果
cat("Spearman rho =", round(rho, 3), "\n")
cat("p-value =", test$p.value, "\n")

运行结果验证

运行代码后应得到一个rho值（例如-0.2~0.2之间）及p值（通常>0.05），说明年龄与VAS评分无显著秩相关。可通过hist(vas)确认数据偏态分布。

注意事项

1. Spearman相关适用于有序数据或非正态连续变量，对异常值不敏感。
2. cor.test()默认计算检验和置信区间，比单纯cor()提供更完整推断。

常见错误

不要对非正态数据直接使用method="pearson"，否则可能低估或高估关联强度。另外，当数据存在重复秩时，cor.test会使用校正公式，结果仍可靠。

成功要点

本例完整展示了秩相关的计算、假设检验和结果解读。学习者可修改样本量或种子值，观察rho变化，加深对"秩"概念的理解。
