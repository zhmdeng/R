案例问题/题目：用R语言survdiff()执行log-rank检验，比较两组模拟患者的生存曲线差异。

环境依赖：R 4.0+，需安装survival包（install.packages("survival")）。仅依赖该包，其余为标准R功能。

完整代码：
library(survival)
set.seed(123)
n <- 60
group <- rep(c("treatment", "control"), each = 30)
time <- c(rweibull(30, shape = 2, scale = 12),
          rweibull(30, shape = 2, scale = 8))
event <- rbinom(n, 1, 0.8)          # 20%删失
data <- data.frame(time, event, group)
# 构建生存对象并执行log-rank
fit <- survdiff(Surv(time, event) ~ group, data = data)
print(fit)

运行命令：
Rscript logrank_example.R

预期运行结果：
Call:
survdiff(formula = Surv(time, event) ~ group, data = data)

              N Observed Expected (O-E)^2/E (O-E)^2/V
control      30       24     15.2      5.12      7.54
treatment    30       25     33.8      2.31      7.54

 Chisq= 7.5  on 1 degrees of freedom, p= 0.006

测试建议：
1. 修改rweibull的scale参数为相同值（如10），重新运行，P值应大于0.05。
2. 将event概率从0.8调低至0.5，观察P值变化，体会删失对检验效能的影响。

常见问题：
1. 若不加载survival包，Surv函数不存在，报错。先install.packages("survival")。
2. 分组变量必须是两水平的因子或字符，若为数值（0/1）也能运行，但建议转因子。
3. 注意Surv()中时间变量必须是数值型，不能为因子或字符。
