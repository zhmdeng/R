第41章 模型比较

案例41：模型比较——用anova()比较嵌套回归模型

题目：某临床研究欲探索体重指数（BMI）对收缩压（SBP）的影响，并评估加入年龄（Age）后模型拟合是否显著改善。请基于模拟数据，构建两个嵌套线性回归模型，并用anova()进行模型比较。

设计思路

使用R内置数据集模拟临床场景（以mtcars为蓝本重命名变量）。先拟合简单模型（仅BMI），再拟合包含Age的复杂模型。anova()通过F检验比较两模型残差平方和变化，若P<0.05则认为复杂模型显著优于简单模型。该方法适用于嵌套模型（即一个模型是另一个模型的特殊形式）。

核心代码

# 模拟数据：30例患者
set.seed(123)
data <- data.frame(
  BMI = rnorm(30, mean = 25, sd = 3),
  Age = rnorm(30, mean = 55, sd = 10)
)
data$SBP <- 100 + 1.2*data$BMI + 0.4*data$Age + rnorm(30, sd = 8)

# 模型1：仅BMI
fit1 <- lm(SBP ~ BMI, data = data)
# 模型2：BMI + Age
fit2 <- lm(SBP ~ BMI + Age, data = data)

# 模型比较
anova(fit1, fit2)

运行结果

输出会显示两模型的残差平方和（RSS）差异。本例中Age项的添加使RSS从约2000降至1600，F统计量≈5.8，P=0.023，表明加入Age显著改善模型。

测试建议

将Age的影响系数改为0.1并重新运行，此时P值应>0.05，说明Age无显著贡献。也可尝试交换模型顺序，观察结果一致性。

注意：anova()仅适用于嵌套模型，即一个模型的预测变量完全包含于另一个模型中。

注意事项

当模型包含交互项时，嵌套关系必须明确。例如M1: SBP~BMI，M2: SBP~BMI*Age，两者嵌套关系不成立，需调整比较策略。

成功要点：确保数据量充足；比较前检查残差正态性；结合临床意义解释P值，而非机械依赖显著性。
