第93章 重复测量方差分析

题目

某临床试验招募12名高血压患者，分别在用药前（time0）、用药4周（time1）、用药8周（time2）测量收缩压（SBP）。每位患者接受三种药物（A、B、C）之一（组间因素drug），但每位患者仅接受一种药物，并在3个时间点重复测量。试分析药物、时间及其交互作用对收缩压的影响。

设计思路

采用混合设计重复测量ANOVA：组内因素为时间（3水平），组间因素为药物（3水平）。使用ezANOVA函数，需将数据转为长格式，并指定受试者ID、组内因素、组间因素。

💡 核心思想

ez包自动处理球形检验（Mauchly's Test），并提供Greenhouse-Geisser校正，避免违反球形假设时结果偏倚。

核心代码

# 安装并加载ez包
# install.packages("ez")
library(ez)

# 模拟数据：12名患者，3药物组，每组4人，3个时间点
set.seed(123)
dat <- data.frame(
  id = rep(1:12, each = 3),
  drug = rep(rep(c("A","B","C"), each = 4), each = 3),
  time = rep(c("time0","time1","time2"), times = 12),
  sbp = c(rnorm(12, 150, 8), rnorm(12, 145, 8), rnorm(12, 138, 8))
)

# 转换时间变量为因子，并设定水平顺序
dat$time <- factor(dat$time, levels = c("time0","time1","time2"))
dat$drug <- factor(dat$drug)

# 执行重复测量ANOVA
res <- ezANOVA(
  data = dat,
  dv = sbp,          # 因变量
  wid = id,          # 受试者ID
  within = time,     # 组内因素
  between = drug,    # 组间因素
  detailed = TRUE,   # 输出详细结果
  type = 3           # III型平方和
)

# 打印结果
print(res)

🔍 运行结果解读

输出包含球形检验（Mauchly's Test of Sphericity）、方差分析表（ANOVA Table）。若球形检验p<0.05，应使用p[GG]和p[HF]列校正后的p值。预期药物主效应、时间主效应显著，交互效应可能不显著。

⚠️ 常见错误

1. wid变量必须为因子型或数值型，但不能有缺失；2. 组内因素levels顺序错误会导致分析结果不同；3. 数据必须为长格式，每行一个观测。

验证方法

运行上述代码后，观察ANOVA Table中的p<.05列。若模拟数据中药物和时间均显著，说明代码正确。可将sbp生成公式中的均值差加大（如A组150，B组140，C组130），更易看到显著效应。

✅ 成功要点

确保wid唯一标识每位受试者；因子水平设置正确；解释结果时优先查看球形校正后的p值。

注意事项

① 若数据违背球形假设，切勿仅报告未校正的p值；② 交互作用显著时，应进行简单效应分析（如按药物分组做单因素重复测量ANOVA）；③ 本模拟数据较小，实际研究建议每组至少10例。
