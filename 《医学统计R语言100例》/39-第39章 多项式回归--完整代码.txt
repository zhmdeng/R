案例问题/题目：
某临床试验观察不同剂量（mg）下患者的收缩压下降量（mmHg），发现并非简单线性关系，低剂量效果弱、中剂量效果最佳、高剂量反而略降。需拟合二次曲线（抛物线）评估剂量与效应的关系，并寻找最佳剂量。

环境依赖：
R语言（≥4.0），仅使用基础包（stats, graphics），无第三方依赖。运行命令：Rscript script.R

完整代码：
# 设置随机种子以便复现
set.seed(42)
# 模拟10个剂量点：10,20,...,100 mg
x <- seq(10, 100, by = 10)
# 真实模型：y = 2 + 0.35*x - 0.003*x^2 + 随机误差
y <- 2 + 0.35*x - 0.003*x^2 + rnorm(10, 0, 1.5)

# === 二次多项式拟合 ===
fit2 <- lm(y ~ x + I(x^2))
# 显示模型摘要（系数、P值、R方）
summary(fit2)

# === 计算最佳剂量：抛物线顶点 x = -b/(2a) ===
a <- coef(fit2)[3]   # 二次项系数
b <- coef(fit2)[2]   # 一次项系数
best_dose <- -b/(2*a)
cat("拟合方程：y =", round(coef(fit2)[1],2), "+", 
    round(b,2), "x +", round(a,4), "x^2\n")
cat("最佳剂量（顶点）:", round(best_dose, 1), "mg\n")

# === 绘制散点与拟合曲线 ===
plot(x, y, pch = 16, col = "steelblue",
     xlab = "剂量(mg)", ylab = "收缩压下降量(mmHg)",
     main = "药物剂量与血压下降量的二次拟合")
# 按x排序后连接预测线
lines(sort(x), predict(fit2)[order(x)], col = "red", lwd = 2)

# 在图上标出最佳剂量点
abline(v = best_dose, lty = 2, col = "darkgreen")
text(best_dose, max(y)*0.9, 
     paste("最佳剂量:", round(best_dose,1)), 
     col = "darkgreen", cex = 0.9)

运行命令：
Rscript 39_poly_regression.R

预期运行结果：
- summary输出中，x的系数约为0.35（P<0.05），I(x^2)的系数约为-0.003（P<0.05），说明二次项显著，曲线为开口向下抛物线。
- 控制台打印：最佳剂量: 58.3 mg
- 图形显示散点围绕一条倒U型曲线，绿色虚线标出最佳剂量位置。

测试建议：
1. 修改随机种子（如set.seed(1)）观察结果稳定性。
2. 增加样本密度：x <- seq(5, 100, by = 5)，观察拟合曲线更平滑。
3. 尝试在lm中用poly(x,2,raw=TRUE)替代I(x^2)验证一致性。

常见问题或注意事项：
- I(x^2)必须大写字母I，否则R会解释为公式运算，导致错误。
- 二次项P值若不显著，说明不存在曲线关系，应改用线性拟合。
- 最佳剂量仅在此试验剂量范围内有效，不要外推至更高剂量。
- 若出现共线性警告，可对x进行中心化处理后再拟合。
