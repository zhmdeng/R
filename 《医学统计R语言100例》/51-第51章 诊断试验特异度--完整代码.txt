案例问题/题目：51、诊断试验特异度：计算特异度并解释含义。基于50名非糖尿病患者的空腹血糖数据，以FPG≥7.0 mmol/L为阳性标准，计算特异度并解释临床意义。

环境依赖：R语言（≥3.5），仅标准库，无第三方包。运行命令：Rscript script.R

完整代码：
# 非糖尿病人群血糖值（mmol/L）
fpg_non_dm <- c(4.2, 5.1, 5.6, 6.2, 6.8, 7.2, 4.8, 5.5, 6.0, 6.5,
                5.9, 4.6, 5.3, 7.1, 6.1, 5.0, 5.8, 6.3, 4.9, 5.4,
                6.7, 5.7, 4.5, 5.2, 6.4, 6.9, 5.1, 4.7, 5.6, 6.6,
                5.0, 5.9, 6.2, 7.0, 5.3, 5.8, 4.4, 5.5, 6.1, 5.7,
                4.8, 5.4, 6.5, 5.2, 6.0, 5.6, 4.9, 6.3, 5.1, 5.8)
# 阳性判定阈值
cutoff <- 7.0
# 判定阳性（≥阈值视为筛查阳性）
test_positive <- fpg_non_dm >= cutoff
# 真阴性（实际上为非糖尿病且筛查阴性）
true_negative <- sum(!test_positive)
n_total <- length(fpg_non_dm)
# 特异度计算
specificity <- true_negative / n_total
cat("非糖尿病总人数：", n_total, "\n")
cat("筛查阴性人数（真阴性）：", true_negative, "\n")
cat("特异度 =", specificity, "(", round(specificity*100, 1), "% )\n")

运行命令：Rscript specificity_example.R

预期运行结果：
非糖尿病总人数： 50 
筛查阴性人数（真阴性）： 47 
特异度 = 0.94 ( 94% )

测试建议：
1. 将cutoff改为6.1，观察特异度变化；
2. 将任意一个血糖值改为8.0，重新运行，特异度应下降；
3. 若数据中含NA，需用na.omit()处理。

常见问题或注意事项：
- 特异度仅反映无病人群中的阴性率，不能替代敏感度或预测值；
- 阈值选择应参考临床指南，不可随意设定；
- 样本量过小会导致特异度估计不稳定，本例50例仅用于演示方法。
