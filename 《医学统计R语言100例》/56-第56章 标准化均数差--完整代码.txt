案例问题/题目：
计算两组收缩压下降值的Cohen's d效应量。A药组（n=20）：均值12.5，标准差3.2；B药组（n=18）：均值9.8，标准差2.9。要求输出d值并解释效应大小。

环境依赖：
R语言（≥4.0），仅标准库，无需第三方包。
运行命令：Rscript cohen_d.R

完整代码：
# 输入两组数据
m1 <- 12.5; sd1 <- 3.2; n1 <- 20
m2 <- 9.8;  sd2 <- 2.9; n2 <- 18

# 合并标准差（pooled SD）
sd_pooled <- sqrt(((n1-1)*sd1^2 + (n2-1)*sd2^2) / (n1+n2-2))

# Cohen's d
d <- (m1 - m2) / sd_pooled

# 输出结果
cat("Cohen's d =", round(d, 3), "\n")

# 解释效应大小
if (abs(d) < 0.2) {
  effect <- "极小"
} else if (abs(d) < 0.5) {
  effect <- "小"
} else if (abs(d) < 0.8) {
  effect <- "中"
} else {
  effect <- "大"
}
cat("效应量大小：", effect, "\n")

运行命令：
Rscript cohen_d.R

预期运行结果：
Cohen's d = 0.878 
效应量大小： 大

测试建议：
1. 修改m1为11.5，预期d约为0.57（中等效应）。
2. 修改sd1为5.0，预期d减小（约0.53）。
3. 可增加一个函数封装，方便重复调用。

常见问题或注意事项：
1. 合并标准差假设两总体方差齐性；若方差不齐，建议改用Welch校正的d公式。
2. Cohen's d的正负号取决于哪个组作为组1，报告时应明确组别标签。
3. 建议同时报告95%置信区间（可用bootstrap法），以评估抽样误差。
