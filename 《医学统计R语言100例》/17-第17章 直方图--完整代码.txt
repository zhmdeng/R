案例问题/题目：
使用R语言内置hist()函数，根据模拟的50名患者年龄数据绘制直方图，并添加均值参考线，观察年龄分布形态。

环境依赖：
- R语言（版本≥4.0，仅标准库，无需安装任何第三方包）
- 运行命令：Rscript hist_demo.R

完整代码：
# 设置随机种子，保证结果可复现
set.seed(123)

# 生成50名患者的年龄（均值55，标准差10）
age <- round(rnorm(50, mean = 55, sd = 10))

# 绘制直方图
hist(age,
     breaks = 8,                 # 分为8个区间
     col = "skyblue",            # 柱体颜色
     border = "white",           # 边框白色
     main = "患者年龄分布直方图",
     xlab = "年龄（岁）",
     ylab = "频数")

# 添加均值竖线（红色虚线）
abline(v = mean(age), col = "red", lwd = 2, lty = 2)

# 在图中添加均值文本
text(mean(age) + 1, 6, 
     paste("均值 =", round(mean(age), 1)), 
     col = "red", pos = 4)

运行命令：
Rscript hist_demo.R

预期运行结果：
图形窗口弹出，显示skyblue色直方图，x轴范围约35~75岁，y轴为频数，一条红色虚线垂直穿过均值位置（约55岁），图右上角标注“均值 = 55.2”等具体数值。

测试建议：
1. 修改breaks=c(4, 8, 12)对比图形变化；
2. 将rnorm中的sd改为5或20，观察分布陡峭或平坦变化；
3. 添加freq=FALSE参数，将纵轴改为密度，并尝试叠加dnorm()曲线。

常见问题或注意事项：
- 若图中出现负年龄，是因为随机数生成导致，可在生成后使用pmax(age, 0)或重新设置种子；
- hist()默认使用Sturges规则自动选组数，手动设置breaks时需谨慎，组数过少会掩盖细节，过多则噪声明显；
- 直方图适合样本量≥30的情况，样本过小时建议使用条形图展示原始频数。
