案例问题/题目：ggplot2直方图——添加密度曲线和分组颜色，比较不同性别患者收缩压分布

环境依赖：
- R语言（≥4.0）
- ggplot2包（运行前install.packages("ggplot2")）
- 运行命令：Rscript 79_histogram_density.R

完整代码：
set.seed(123)
library(ggplot2)

data <- data.frame(
  sex = rep(c("男性", "女性"), each = 200),
  sbp = c(rnorm(200, 135, 12), rnorm(200, 128, 10))
)

p <- ggplot(data, aes(x = sbp, fill = sex)) +
  geom_histogram(aes(y = after_stat(density)),
                 position = "identity",
                 alpha = 0.5,
                 bins = 30,
                 color = "white") +
  geom_density(aes(color = sex), alpha = 0.4, linewidth = 1) +
  scale_fill_manual(values = c("男性" = "#4E79A7", "女性" = "#F28E2B")) +
  scale_color_manual(values = c("男性" = "#4E79A7", "女性" = "#F28E2B")) +
  labs(title = "收缩压分布（分组直方图+密度曲线）",
       x = "收缩压 (mmHg)", y = "密度") +
  theme_minimal(base_size = 14)

print(p)

运行命令：
Rscript 79_histogram_density.R

预期运行结果：
生成一张双色重叠直方图，男性曲线峰值约135，女性约128，两条密度曲线清晰叠加在直方图上。

测试建议：
1. 修改bins值（如15/50)观察直方图形态变化；
2. 更换scale_fill_manual中的颜色值测试视觉可读性；
3. 将数据量改为500/组验证稳定性。

注意事项：
1. 务必使用after_stat(density)，否则直方图纵轴为频数，与密度曲线不匹配；
2. position="identity"保证直方图不堆叠，否则无法看到分组重叠效果；
3. 分组变量需为因子类型，否则fill映射可能出错。
