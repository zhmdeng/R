案例问题/题目：
某医院门诊记录中包含5种疾病类型，请使用barplot()绘制不同疾病类型的计数条形图，并完成基本图形修饰（颜色、标题、坐标轴、柱顶数值）。

环境依赖：
- 语言：R语言（>= 3.6.0）
- 运行命令：Rscript 或 RStudio中直接运行
- 第三方依赖：仅标准库（graphics包自动加载，无需额外安装）

完整代码：
# 1. 构建数据
disease <- c("高血压", "糖尿病", "肺炎", "胃炎", "关节炎")
counts <- c(45, 32, 28, 21, 15)

# 2. 设置边距（避免中文标签被截断）
par(mar = c(6, 4, 4, 2))

# 3. 绘制条形图
barplot(counts,
        names.arg = disease,
        col = "steelblue",
        main = "门诊疾病类型分布",
        xlab = "疾病类型",
        ylab = "就诊人数",
        ylim = c(0, 50),
        las = 2,          # 横轴标签旋转90度
        cex.names = 0.9)  # 标签字号

# 4. 在柱顶添加数值
text(x = 0.7 + 1.2*(0:4),
     y = counts + 1.5,
     labels = counts,
     cex = 0.8)

运行命令：
Rscript barplot_disease.R

预期运行结果：
生成一个条形图窗口，显示5根垂直柱子，颜色为steelblue，纵轴范围为0~50，每根柱顶有对应数值（45,32,28,21,15），横轴为旋转90度的中文疾病名称，标题为“门诊疾病类型分布”。

测试建议：
1. 修改counts数据为不同数值，观察条形高度变化。
2. 将col参数改为"tomato"或其他颜色，验证颜色变化。
3. 将ylim改为c(0, 60)，观察纵轴范围变化。

常见问题或注意事项：
1. 若中文显示为方块，需在R中设置中文字体支持，例如：windowsFonts(CN = windowsFont("SimSun"))，并在barplot中添加family = "CN"。
2. 柱顶数值位置(x坐标)是基于barplot默认间距计算的，若调整了barplot宽度参数space，需要相应修改x坐标公式。
3. 若图形显示不全，可增大par(mar)中的边距数值。
