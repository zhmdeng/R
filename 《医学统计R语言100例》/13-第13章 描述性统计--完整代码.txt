案例问题/题目：对50名患者的模拟临床数据（年龄、收缩压、BMI、住院天数、性别），使用summary()函数一次性输出所有数值变量的最小值、1st四分位数、中位数、均值、3rd四分位数、最大值，并输出因子变量性别的频数统计。

环境依赖：R语言 ≥ 4.0，仅使用R基础包，无第三方依赖。运行命令：Rscript case13.R

完整代码：
# 设置随机种子，保证结果可复现
set.seed(2024)

# 生成50名患者的模拟数据
data <- data.frame(
  年龄 = rnorm(50, mean = 45, sd = 10),
  收缩压 = rnorm(50, mean = 130, sd = 15),
  BMI = rnorm(50, mean = 24, sd = 3),
  住院天数 = rpois(50, lambda = 6)
)

# 添加一个因子型变量：性别
data$性别 <- factor(sample(c("男","女"), 50, replace = TRUE))

# 用summary()一次输出所有变量的描述统计
summary(data)

# 额外验证：查看数据结构
cat("\n--- 数据结构 ---\n")
str(data)

# 额外验证：检查缺失值数量
cat("\n--- 缺失值统计 ---\n")
sum(is.na(data))

运行命令：Rscript case13.R

预期运行结果：
对四个数值变量（年龄、收缩压、BMI、住院天数）各输出6行统计量：Min.、1st Qu.、Median、Mean、3rd Qu.、Max.。
对因子变量“性别”输出频数计数，如男:27 女:23。

测试建议：
1. 修改随机种子或样本量（如100），重新运行，观察统计量变化是否合理。
2. 尝试在数据中加入一列含NA的变量，观察summary()默认输出不显示NA，而sum(is.na(data))能检测缺失值。
3. 将“性别”改为字符型（不用factor()），对比summary()输出差异（字符型只显示"Length"和"Class"）。

常见问题或注意事项：
- summary()对数值型变量计算四分位数时采用type=7默认算法，与SPSS略有不同，但偏差很小。
- 若数据含缺失值，summary()只计算非缺失部分，但不提示缺失数量。建议配合sum(is.na())使用。
- 对因子型变量，summary()输出频数；对字符型变量则输出长度与类别数。若需字符型的频数表，请先转为factor或使用table()。
