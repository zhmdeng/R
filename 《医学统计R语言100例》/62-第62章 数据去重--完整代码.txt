案例问题/题目：
某临床试验患者记录包含ID、姓名、随访日期、疗效评分，因数据合并产生重复行。请用unique()删除完全重复行，再用dplyr::distinct()按ID+随访日期去重，保留首次记录，并比较结果。

环境依赖：
R语言（≥4.0），需安装tidyverse（含dplyr包）。运行命令：Rscript case62.R

完整代码：
# case62.R
library(dplyr)

df <- data.frame(
  ID = c(101,101,102,102,103),
  姓名 = c("张三","张三","李四","李四","王五"),
  随访日期 = c("2024-01-01","2024-01-01","2024-01-02","2024-01-03","2024-01-04"),
  疗效 = c(85,85,90,88,92)
)

cat("原始行数:", nrow(df), "\n")

# 完全去重
a <- unique(df)
cat("unique()去重后行数:", nrow(a), "\n")

# 按ID+随访日期去重
b <- distinct(df, ID, 随访日期, .keep_all = TRUE)
cat("distinct()指定列去重后行数:", nrow(b), "\n")
print(b)

运行命令：
Rscript case62.R

预期运行结果：
原始行数: 5 
unique()去重后行数: 4 
distinct()指定列去重后行数: 4 
  ID 姓名 随访日期 疗效
1 101 张三 2024-01-01  85
2 102 李四 2024-01-02  90
3 102 李四 2024-01-03  88
4 103 王五 2024-01-04  92

测试建议：
将第2条随访日期改为"2024-01-05"再运行，观察distinct()结果行数变为5。

常见问题：
1. unique()只适用于行完全相同的去重，若字段顺序不同则视为不同行。
2. distinct()中若使用.keep_all=FALSE（默认），则仅保留去重列，其他列被丢弃，注意设置.
keep_all=TRUE保留所有列。
3. 字符型日期务必统一格式，如"2024-01-01"与"2024/1/1"会被视为不同值。
