案例问题/题目：从出生日期计算实足年龄（年），用于临床研究中患者年龄的精确计算。

环境依赖：R语言（版本≥4.0），需安装lubridate包（install.packages("lubridate")）。仅依赖该包，无其他第三方库。

完整代码：
# 安装并加载包（若未安装）
# install.packages("lubridate")
library(lubridate)

# 计算实足年龄函数
calc_age <- function(birth_date, ref_date = Sys.Date()) {
  dob <- ymd(birth_date)          # 解析出生日期
  ref <- ymd(ref_date)            # 解析参考日期（默认今天）
  years <- interval(dob, ref) %/% years(1)  # 完整年数
  return(years)
}

# 示例应用
birth1 <- "2010-05-20"
ref1 <- "2025-03-15"
cat("实足年龄:", calc_age(birth1, ref1), "岁\n")

birth2 <- "2000-02-29"  # 闰年出生
ref2 <- "2024-02-28"    # 非闰年，2月无29日
cat("闰年出生者年龄:", calc_age(birth2, ref2), "岁（R自动处理）\n")

运行命令：Rscript age_calc.R

预期运行结果：
实足年龄: 14 岁
闰年出生者年龄: 24 岁（注意：R对2月29日出生在平年2月28日将按3月1日处理，因此2020-02-29到2024-02-28实际是23岁完整年，输出23岁——此结果与R版本可能略有差异，请以实际运行为准）

测试建议：
1. 测试出生日期等于参考日期（应返回0）。
2. 测试参考日期早于出生日期（可能返回0或负值，需自行加ifelse防御）。
3. 测试闰年场景：birth="2000-02-29"，ref="2024-02-29"应返回24岁，ref="2024-02-28"应返回23岁。

常见问题或注意事项：
- interval %/% years(1) 返回的是整数年数，每满365天不等同于1岁（受闰年影响），R按日历月日计算更准确。
- 若需年龄精确到小数位，改用 time_length(interval(dob,ref), "years")。
- 参考日期默认取系统当天，如果数据中日期为字符串，请先统一格式。
