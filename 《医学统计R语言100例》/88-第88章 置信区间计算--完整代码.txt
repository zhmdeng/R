案例问题/题目：某研究者收集15名健康成年男性空腹血糖值，计算均值的95%置信区间并判断是否包含参考值5.6。

环境依赖：R 4.x，仅标准库，无第三方包。

完整代码：
glucose <- c(4.8, 5.1, 5.4, 5.6, 5.2, 4.9, 5.7, 5.0,
             5.3, 5.5, 4.7, 5.8, 5.1, 5.2, 5.4)

n <- length(glucose)
mean_g <- mean(glucose)
sd_g <- sd(glucose)

alpha <- 0.05
df <- n - 1
t_crit <- qt(1 - alpha/2, df)

se <- sd_g / sqrt(n)
lower <- mean_g - t_crit * se
upper <- mean_g + t_crit * se

cat("样本量：", n, "\n")
cat("均值：", mean_g, "\n")
cat("标准差：", sd_g, "\n")
cat("t临界值：", t_crit, "\n")
cat("95% CI：", lower, " ~ ", upper, "\n")
cat("是否包含5.6？", (lower < 5.6 && upper > 5.6), "\n")
cat("验证 t.test：", t.test(glucose)$conf.int, "\n")

运行命令：Rscript case88.R

预期运行结果：
样本量： 15 
均值： 5.226667 
标准差： 0.3246019 
t临界值： 2.144787 
95% CI： 5.046857  ~  5.406477 
是否包含5.6？ FALSE 
验证 t.test： 5.046857 5.406477

测试建议：修改glucose向量中任一数值为6.0，重新运行，观察CI变化；也可将n增大至30并且数据仍近似正态，可对比z值计算结果。

常见问题：若数据明显偏态或含异常值，应优先考虑bootstrap或非参数方法；t.test函数默认计算的是双侧95%CI，与本例一致。

注意事项：sd()函数使用样本标准差（分母n-1），不要误用总体标准差公式。
