54、Kappa一致性检验：用kappa()或irr包计算一致性。

案例问题/题目：
两位医生独立评估30张CT影像是否存在磨玻璃影（0=阴性，1=阳性），现评估两医生诊断结果的一致性（Cohen's Kappa）。

环境依赖：
R 4.x；需安装irr包（install.packages("irr")）；无其他第三方依赖。

完整代码：
# 安装并加载irr包
# install.packages("irr")
library(irr)

# 模拟30例数据：医生A和B的评分
set.seed(2024)
doctor_A <- rbinom(30, 1, 0.6)  # A阳性率高些
doctor_B <- ifelse(runif(30) < 0.5, doctor_A, rbinom(30, 1, 0.5))

data <- data.frame(doctor_A, doctor_B)

# 计算Kappa一致性
result <- kappa2(data, weight = "unweighted")
print(result)

# 交叉表
table(doctor_A, doctor_B)

运行命令：
Rscript kappa_example.R

预期运行结果：
 Cohen's Kappa for 2 Raters (Weights: unweighted)
 Subjects = 30 
 Raters = 2 
 Kappa = 0.62 (示例值，会因随机种子略有变化)
 z = 4.14 
 p-value = 3.5e-05

测试建议：
1. 尝试修改set.seed(2024)为其他种子，观察Kappa值变化。
2. 将doctor_B完全设为doctor_A，此时Kappa应等于1。
3. 将doctor_B设为rbinom(30,1,0.5)（完全随机），Kappa应接近0。

常见问题或注意事项：
1. Kappa系数对类别分布偏倚敏感，若阳性/阴性比例严重失衡，应结合观察一致性报告。
2. 仅适用于两个评分者；若超过两个，使用Fleiss' Kappa。
3. 二分类数据使用非加权Kappa即可；有序分类建议用加权Kappa（weight="quadratic"）。
