案例问题/题目：用data.frame()创建包含ID、性别、血压的简易数据集，并完成结构查看与基本统计。

环境依赖：
- 语言/版本：R 4.2.0及以上
- 运行命令：Rscript chapter3.R
- 第三方依赖：仅标准库，无需额外安装包

完整代码：
# 1. 创建数据框
df <- data.frame(
  ID = c(1, 2, 3, 4, 5),
  性别 = factor(c("男", "女", "女", "男", "女")),
  血压 = c(120, 135, 118, 142, 129)
)

# 2. 查看数据前两行
print(head(df, 2))

# 3. 检查数据结构
str(df)

# 4. 显示血压均值（验证数据可计算）
cat("平均血压：", mean(df$血压), "mmHg\n")

运行命令：
Rscript chapter3.R

预期运行结果：
  ID 性别 血压
1  1   男  120
2  2   女  135
'data.frame':	5 obs. of  3 variables:
 $ ID  : num  1 2 3 4 5
 $ 性别: Factor w/ 2 levels "男","女": 1 2 2 1 2
 $ 血压: num  120 135 118 142 129
平均血压： 128.8 mmHg

测试建议：
1. 将血压列改为 c(120, NA, 118, 142, 129)，验证 mean() 返回 NA。
2. 尝试使用 names(df) 查看列名，或 nrow(df) 获取行数。
3. 将性别列替换为字符串向量，再用 as.factor() 转换，观察 str() 输出变化。

常见问题或注意事项：
1. 中文列名在部分图形设备（如PDF）可能显示乱码，建议分析前用 names(df) <- c("ID", "gender", "bp") 重命名。
2. factor() 默认按字母顺序排列水平，如需自定义顺序请指定 levels 参数。
3. data.frame() 会自动把字符串列转换为因子，若想保持字符串原样，请加 stringsAsFactors = FALSE 参数。
