案例问题/题目：
某新型快速检测试剂用于筛查某疾病，对200名疑似患者同时进行金标准检查（病理活检）和快速试剂检测。结果：金标准阳性且试剂阳性120例，金标准阳性但试剂阴性30例，金标准阴性但试剂阳性20例，金标准阴性且试剂阴性30例。计算该诊断试验的灵敏度（Sensitivity）。

环境依赖：
R语言（仅标准库，无第三方依赖）。运行命令：Rscript sensitivity.R

完整代码：
# 构建2×2列联表数据
# 行：金标准（阳性/阴性）
# 列：快速试剂（阳性/阴性）
tp <- 120   # 真阳性
fn <- 30    # 假阴性
fp <- 20    # 假阳性
tn <- 30    # 真阴性

# 计算灵敏度（%）
sensitivity <- tp / (tp + fn) * 100
cat("灵敏度 =", round(sensitivity, 1), "%\n")

# 计算95%置信区间（Wald法）
se <- sqrt(sensitivity * (100 - sensitivity) / (tp + fn))
ci_lower <- sensitivity - 1.96 * se
ci_upper <- sensitivity + 1.96 * se
cat("95%置信区间（Wald法）:", round(ci_lower, 1), "%~",
    round(ci_upper, 1), "%\n")

# 可选：构建混淆矩阵展示
confusion_matrix <- matrix(c(tp, fp, fn, tn), nrow = 2, byrow = TRUE,
                           dimnames = list("金标准" = c("阳性", "阴性"),
                                           "试剂" = c("阳性", "阴性")))
print(confusion_matrix)

运行命令：
Rscript sensitivity.R

预期运行结果：
灵敏度 = 80 %
95%置信区间（Wald法）: 73.2 %~ 86.8 %

测试建议：
1. 修改tp和fn的值，验证极端情况：tp=150, fn=0时灵敏度应为100%。
2. 调整fp和tn的值不影响灵敏度计算，但影响特异度。
3. 若灵敏度接近100%或0%，建议改用Wilson方法计算置信区间。

常见问题或注意事项：
1. 灵敏度只与真阳性（tp）和假阴性（fn）有关，与假阳性（fp）、真阴性（tn）无关。
2. Wald法置信区间在极端比例下不稳定，临床论文中推荐使用Wilson法或精确法。
3. 本例样本量200，临床实际中应报告样本量来源及疾病患病率背景。
