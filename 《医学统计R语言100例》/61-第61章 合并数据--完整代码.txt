案例问题/题目：按ID合并两个数据框（merge()内连接基础）
环境依赖：R 4.0+；仅标准库（base）
完整代码：
# 建立基本资料数据框
demo <- data.frame(
  ID = c(1, 2, 3, 4, 5),
  sex = c("女", "男", "女", "男", "女"),
  age = c(45, 52, 38, 61, 47)
)

# 建立随访结局数据框（含缺失ID）
follow <- data.frame(
  ID = c(2, 3, 4, 5, 6),
  relapse = c("否", "是", "否", "是", "否"),
  days = c(360, 182, 540, 240, 720)
)

# 按ID合并（内连接）
merged <- merge(demo, follow, by = "ID")
print(merged)

# 关键验证
cat("合并后行数:", nrow(merged), "\n")
cat("ID1数据丢失（因随访缺失）:", !1 %in% merged$ID, "\n")
运行命令：Rscript script.R 或 RStudio中直接运行
预期运行结果：
  ID sex age relapse days
1  2  男  52     否  360
2  3  女  38     是  182
3  4  男  61     否  540
4  5  女  47     是  240
合并后行数: 4
ID1数据丢失（因随访缺失）: TRUE
测试建议：
1. 将demo中ID=6的数据加入，观察内连接行为。
2. 将merge参数改为all=TRUE，对比外连接结果。
3. 将ID改为字符型（如"P01"），确认merge仍能正确匹配。
常见问题或注意事项：
- 两个数据框的ID列必须同类型（数值/字符），否则无法匹配。
- 默认内连接会丢弃不匹配的ID，注意检查样本量变化。
- 若ID存在重复值，合并可能产生多行笛卡尔积，需事先核实ID唯一性。
