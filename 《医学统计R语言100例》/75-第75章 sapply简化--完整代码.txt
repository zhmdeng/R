案例问题/题目：
某临床数据集包含50名患者的年龄、收缩压和心率。需快速计算各变量的均值、中位数、标准差，并以简洁结果返回，比较lapply()与sapply()的输出差异。

环境依赖：
R语言（>= 4.0），仅标准库，无需第三方包。运行命令：Rscript ch75_sapply.R

完整代码：
set.seed(123)
data <- data.frame(
  年龄 = round(rnorm(50, 60, 10)),
  收缩压 = round(rnorm(50, 130, 15)),
  心率 = round(rnorm(50, 75, 8))
)

stats <- function(x) c(
  均值 = round(mean(x), 1),
  中位数 = median(x),
  标准差 = round(sd(x), 2)
)

result_l <- lapply(data, stats)
result_s <- sapply(data, stats)

print("lapply()结果：")
print(result_l)
print("sapply()结果（矩阵）：")
print(result_s)
cat("\nsapply()维度：", dim(result_s), "\n")

# 直接提取所有变量的均值
cat("各变量均值：", result_s["均值", ], "\n")

运行命令：
Rscript ch75_sapply.R

测试建议：
1. 修改stats()函数使其仅返回均值（单个数值），再次运行sapply()，观察输出从矩阵自动退化为命名向量。
2. 在stats()中故意让不同变量返回不同长度（如当x均值>70时多返回一个值），观察sapply()退化为列表的现象。

常见问题或注意事项：
1. sapply()的简化依赖结果长度：所有结果长度一致时返回矩阵或向量，不一致时返回列表。
2. 为获得稳定且可预测的输出类型，推荐使用vapply()并指定FUN.VALUE参数。
3. 本案例中round()用于控制小数位数，实际应用中可根据需要调整有效数字。
